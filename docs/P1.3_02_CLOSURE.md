## 4. Limitações, uso pessoal e etapas futuras

- Ambiente ensaiado: MRI Ruby 3.3.6, Psych 5.1.2/libyaml0.2.5, Linux x86_64, openat2 efetivo/procfs e filesystem local suportado. Windows, rede/sincronização, outras ABIs e distribuição não homologados. Sem fallback para openat simples.
- Sem snapshot atômico, pertença contínua ou revogação de descritor após movimento externo; alterações in-place/restaurações entre checkpoints podem escapar. Sem isolamento contra mesmo UID/root. Atime do SO pode mudar e não é restaurado.
- Prazos cooperativos: callbacks não preemptam toda execução/alocação C. Bytes/depth/nós/cardinalidades limitam o trabalho aceito, mas não provam resistência universal a bugs da libyaml. Unicidade vale somente na observação completa de cada tipo, nunca global/eterna ou como autorização de publicação.
- Tetos ensaiados02: 2 MiB/arquivo, 64 KiB/header/marker, 2.048 LF YAML, 16 containers/4.096 nós, 256 pares/map, 512 itens/seq, 8 KiB/scalar, 19 dígitos de versão, IDs/key/tag/label 4.096/128/256/1.024 bytes, 32 diagnósticos e 100ms cooperativos/documento. Agregador: 10.000 entradas/8 MiB de texto retido. Budget01: 32 MiB/5s por operação; profundidade de filesystem 8 continua separada do nesting YAML 16. Excesso não vira truncamento aceito.
- Sem edição genérica de propriedades; composição nova não autoriza publicação. Não há compatibilidade universal prometida com editores/gramáticas YAML externos, renderer HTML/Markdown, scanner operacional, índice persistente, rotas ou interface nova.
- **Nível C não autorizado:** sem Vault pessoal, importação real, migração ou uso com dados pessoais importantes. Homologação técnica/sintética não concede liberação operacional. Recuperação conjunta sem origem, redundância/proteção/custódia de backups/chaves, procedimento por operador e pendências humanas P1.2/01 permanecem.

P1.3-03 depende de autorização própria para o índice SQLite/FTS5 separado, com domínio P1.2 intacto. P1.3-04 depende de protocolo/autorização de escrita, revalidações e Gate de Recuperação Mínima A-01. Renderer/interface, vínculos operacionais e backup conjunto têm gates próprios nos cortes posteriores. Nenhum destes trabalhos é iniciado por este commit.
